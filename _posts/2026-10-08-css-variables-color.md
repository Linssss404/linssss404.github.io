配色是新手最容易写乱的地方。页面写着写着，就出现 `#e66c8d`、`#e56b8c`、`#e76d8e` 三个几乎一样的粉色。想统一换风格时，只能全局搜索替换，还容易漏。

## 把颜色收进变量

把会用到的颜色都定义在 `:root` 里，取一个能描述用途的名字：

```css
:root {
  --ink: #1b2130;        /* 正文 */
  --muted: #667085;      /* 次要文字 */
  --paper: #ffffff;      /* 卡片背景 */
  --accent: #4f5bd5;     /* 主色 */
  --accent-2: #0f8f7d;   /* 辅助色 */
  --line: rgba(27, 33, 48, .12);
}
```

写样式时只引用变量，不再出现十六进制色值：

```css
.card {
  color: var(--ink);
  background: var(--paper);
  border: 1px solid var(--line);
}
.card-link { color: var(--accent); }
```

## 为什么用「用途」而不是「颜色」命名

`--pink` 这种名字会在你把主题改成蓝色时变成一个谎。`--accent` 不会——它只说「这是主色」，具体是什么颜色由变量值决定。

## 换主题只改一处

想换成深色，只需要重写这几行：

```css
:root {
  --ink: #e8ecf4;
  --paper: #161b26;
  --line: rgba(255, 255, 255, .14);
}
```

所有引用变量的组件会自动跟着变，这就是变量最实际的好处。

> 小提示：`rgba()` 里也可以用变量，但透明度需要单独写，所以像 `--line` 这种我会直接连透明度一起定义好。

配色不复杂，难的是「统一」。变量正好解决这一点。
